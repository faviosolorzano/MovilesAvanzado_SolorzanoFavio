# Calculadora de Préstamos

## Descripción

Esta actividad implementa una calculadora de préstamos utilizando UIKit en Swift. El programa trabaja con el capital inicial, la tasa de interés anual y el plazo del préstamo para calcular la cuota mensual y el monto total a pagar.

## Requerimientos funcionales

### RF01 - Ingresar el capital inicial
El sistema debe permitir ingresar el monto inicial del préstamo.

### RF02 - Ingresar la tasa de interés anual
El sistema debe permitir ingresar la tasa de interés anual del préstamo.

### RF03 - Ingresar el plazo del préstamo
El sistema debe permitir ingresar el plazo del préstamo expresado en años.

### RF04 - Validar los datos ingresados
El sistema debe verificar que el capital, la tasa anual y el plazo tengan valores válidos antes de realizar el cálculo.

### RF05 - Calcular la cuota mensual
El sistema debe calcular la cuota mensual utilizando el capital, la tasa de interés mensual y el número total de pagos.

### RF06 - Calcular el monto total
El sistema debe calcular el monto total a pagar multiplicando la cuota mensual por el número total de pagos.

### RF07 - Mostrar los resultados
El sistema debe mostrar la cuota mensual y el monto total a pagar.
