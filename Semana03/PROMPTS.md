# LAB 03 - Colecciones: Arrays, Diccionarios y Sets

## Ejercicio 6 - Gestión de notas

### Contexto
Estoy desarrollando un laboratorio en Swift sobre colecciones, específicamente arreglos y diccionarios.

### Tarea
Crear un programa que solicite N alumnos, registre el nombre y 3 notas de cada alumno, calcule su promedio y muestre su clasificación.

### Requisitos
- Utilizar un diccionario de tipo [String: [Double]].
- Registrar el nombre y 3 notas por alumno.
- Calcular el promedio de cada alumno.
- Clasificar con switch en Excelente, Bueno, Aprobado o Desaprobado.
- Calcular el promedio general.
- Obtener la nota más alta y la nota más baja.
- Calcular el porcentaje de alumnos aprobados.
- Ordenar a los alumnos según su promedio.
- Comentar cada línea del código.

### Formato
Generar código Swift compatible con Playground, ordenado y comentado línea por línea.

### Ejemplo
Registrar varios alumnos con sus tres notas y mostrar al final sus promedios, clasificación, estadísticas generales y ranking.


## Ejercicio 7 - Sistema de inventario

### Contexto
Estoy desarrollando un laboratorio en Swift sobre colecciones y necesito implementar un sistema de inventario.

### Tarea
Crear un programa que registre N productos con nombre, precio y stock, y permita consultar la información mediante un menú interactivo.

### Requisitos
- Registrar nombre, precio y stock de cada producto.
- Utilizar un ciclo while para mantener activo el menú.
- El menú debe tener las siguientes opciones:
  1. Ver inventario.
  2. Buscar producto.
  3. Mostrar productos con stock bajo.
  4. Calcular el valor total del inventario.
  5. Salir.
- Mostrar los resultados de manera ordenada.
- Comentar cada línea del código.

### Formato
Generar código Swift compatible con Playground, organizado y comentado línea por línea.

### Ejemplo
Registrar productos y posteriormente utilizar el menú para consultar el inventario, buscar un producto, revisar el stock bajo y calcular el valor total.
